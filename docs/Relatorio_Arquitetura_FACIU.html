A Maior Dívida Técnica

🚨 O Padrão "Teia de Aranha" (Global State + Patching Excessivo)

A maior ameaça à sustentabilidade do FACIU não é o fato de ser um arquivo único (Single-File App), mas sim a falta de encapsulamento e isolamento de escopo dentro desse arquivo.

  • 31 Blocos de Script: Ao longo do tempo, novas features (como o faciuUnifiedHelpScript, faciuRiaGenerator, faciuAppHelpPageScript) foram sendo adicionadas como "patches" sequenciais (novas tags <script>) no final do arquivo.
  • Conflitos de Ciclo de Vida: O código possui dezenas de document.addEventListener('DOMContentLoaded') disparando de forma assíncrona, dependendo da ordem de carregamento do navegador para não quebrar o estado.
  • Acoplamento Extremo (DOM + Lógica): A lógica de negócio (o que define uma causa raiz) está misturada no mesmo bloco de código que injeta HTML na tela (innerHTML) e lê do localStorage.
  • Estado Global Mutável: Variáveis vitais ficam expostas no escopo global. Qualquer bloco de script pode, a qualquer momento, alterar dados críticos da investigação silenciosamente.

Plano de Refatoração (Por onde começar)

Considerando que o formato SFA (arquivo único .html) tem enorme valor tático para distribuição offline, a refatoração não deve envolver a separação em dezenas de arquivos externos. Ela deve focar em organizar a arquitetura interna do JavaScript.

1

Consolidar o Ciclo de Vida (Lifecycle)

Remover os mais de 10 listeners soltos de DOMContentLoaded. Criar uma única função initFaciuApp() que orquestra a ordem exata de inicialização: carregarEstado() → iniciarModulos() → aplicarConfiguracoes() → renderizarTelaAtual(). Isso elimina condições de corrida e falhas silenciosas no carregamento.

2

Unificar o Gerenciamento de Estado (Store)

Parar de acessar o localStorage e variáveis globais espalhadas em 50 lugares diferentes. Criar um objeto FaciuStore centralizado. Todo módulo que quiser salvar ou ler algo deve perguntar ao FaciuStore. Isso torna o código previsível e facilita a implementação futura de "Desfazer/Refazer" e autosave confiável.

3

Isolar Módulos em Namespaces

Juntar os 31 blocos de <script> em um escopo estruturado. Em vez de funções globais flutuando, agrupar responsabilidades: Faciu.Graph, Faciu.RIA, Faciu.AI, Faciu.UI. Uma função no gerador de RIA nunca deve acessar diretamente um elemento HTML escondido na aba de 5 Porquês.

4

Remover Eventos Inline (Unobtrusive JS)

Limpar o HTML de chamadas como onclick="goStep(...)". O JavaScript deve ser responsável por buscar os botões (via data-action="next-step") e atrelar os eventos. Isso limpa drasticamente o tamanho do HTML e separa visualização de comportamento.
