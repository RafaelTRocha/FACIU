Crítico Linhas 16972 e 18340-18351
Runtime Crash

Colisão no Modal da Prévia RIA e Risco de TypeError Null

Existem duas funções que injetam o elemento #riaPreviewModal no DOM: openRiaPreview() e mostrarPrevia(). A versão de openRiaPreview() cria a modal sem o botão #riaPreviewPdf. Se o usuário abre a prévia simplificada primeiro e posteriormente aciona a visualização completa via window.faciuRiaPreview(), o elemento modal já existe, mas modal.querySelector('#riaPreviewPdf') retorna null, causando exceção fatal não tratada ao tentar atribuir .onclick.

// Linha 18351: Crash quando openRiaPreview() executou primeiro modal.querySelector('#riaPreviewPdf').onclick = () => baixarPdf(modoPrev); // TypeError: Cannot set properties of null (setting 'onclick')

Crítico Linhas 9044, 9047, 9050 vs 19562, 19565, 19568
DOM Integrity

IDs Duplicados nos Botões de Ação do Auditor IA

Os elementos id="btnAiRunAudit", id="btnAiCopyCopilot" e id="btnAiCopyResult" estão declarados simultaneamente no HTML estático da modal #aiAuditorModal e são novamente injetados via innerHTML dentro de FACIUAssistant.renderStatusDiv(). Embora o container seja sobrescrito no runtime, ter IDs duplicados no template viola os padrões W3C e impede seletores seguros antes da primeira renderização.

// Linhas 9044 e 19562: ID id="btnAiRunAudit" duplicado // Linhas 9047 e 19565: ID id="btnAiCopyCopilot" duplicado // Linhas 9050 e 19568: ID id="btnAiCopyResult" duplicado
Ação Recomendada: Manter os botões apenas no template estático ou injetá-los dinamicamente com IDs exclusivos para cada estado.
Crítico Linha 7938
Syntax / Event Safety

Quebra de Sintaxe em Arquivo com Aspas no Catálogo de Pasta de Trabalho

Ao listar arquivos no modal de gestão de pasta de trabalho, o nome do arquivo é injetado diretamente em um atributo onclick: onclick="closeWorkspaceManager(); FaciuFolderMonitor.bindAndLoadFile('${escapeHtml(f.name)}')". Em atributos HTML, entidades como &#039; são decodificadas pelo parser antes da execução JS. Nomes como Incidente d'Água.json geram FaciuFolderMonitor.bindAndLoadFile('Incidente d'Água.json'), causando erro fatal de sintaxe JavaScript.

// Linha 7938: Interpolação direta dentro de atributo inline <button type="button" onclick="closeWorkspaceManager(); FaciuFolderMonitor.bindAndLoadFile('${escapeHtml(f.name)}')">
Ação Recomendada: Substituir o handler inline por atributo de dados: data-filename="${encodeURIComponent(f.name)}" e delegar o evento ou vincular via addEventListener.
Alerta de UI Linha 9982
Visual Consistency

Modo Escuro Não Ativa Classes Tailwind no Carregamento Inicial

A configuração do Tailwind na linha 14 define darkMode: 'class'. No entanto, o script de inicialização do tema no boot (linha 9982) apenas executa document.documentElement.dataset.theme='dark', esquecendo de chamar document.documentElement.classList.add('dark'). Com isso, as variáveis CSS são aplicadas, mas todas as classes utilitárias com prefixo dark: (como dark:bg-... e dark:border-...) falham até que o usuário clique duas vezes no botão de alternância de tema.

// Linha 9982 atual: if(localStorage.getItem('brava_theme')==='dark') document.documentElement.dataset.theme='dark'; // Correção cirúrgica: if(localStorage.getItem('brava_theme')==='dark') { document.documentElement.dataset.theme='dark'; document.documentElement.classList.add('dark'); }
Ação Recomendada: Adicionar document.documentElement.classList.add('dark') na inicialização imediata do boot.

Paleta & Tipografia Linhas 1491, 2042, 10442
Design System Brava

Remanescentes de Cores Âmbar e Fontes Não Padronizadas

A paleta corporativa estrita da Brava Energia define o Roxo Profundo (#1d1343) e o Lima Elétrico (#d0f50d). Na seção Portanto (linhas 1491-1515), gradientes âmbar legados (#f59e0b, #d97706, #fbbf24) ainda são usados. Além disso, o overlay de carregamento (linha 2042) e a renderização do grafo Cytoscape (linhas 10442, 10465) declaram a fonte Inter em vez da tipografia oficial IBM Plex Sans.

Ação Recomendada: Atualizar os gradientes do Portanto para a paleta Brava (var(--navy) e var(--lime)) e unificar o Cytoscape para usar IBM Plex Sans.
Segurança Linhas 9, 56-64
Dependências & SRI

Play CDN do Tailwind e Falta de Subresource Integrity (SRI)

O monólito carrega o script https://cdn.tailwindcss.com sem fixação de versão (Play CDN), que é explicitamente não recomendado em ambientes produtivos pelo Tailwind Labs por compilar estilos em tempo de execução no cliente. Além disso, as bibliotecas externas em CDN (Cytoscape, Sortable, jsPDF, Lucide) não possuem atributos integrity (SRI) ou fallbacks em caso de falha de rede ou indisponibilidade de CDN corporativo.

Ação Recomendada: Compilar o CSS Tailwind estático no build ou adicionar hashes SRI em todas as tags <script> de CDNs externos.
Atalhos Globais Linhas 9934-9944
Usabilidade

Interceptação de Ctrl+Z em Campos de Entrada e Áreas de Texto

O tratador global de teclado intercepta Ctrl+Z e Ctrl+Y sem verificar se o foco atual está dentro de um elemento <input>, <textarea> ou elemento editável. Se o usuário estiver redigindo uma descrição longa e errar uma palavra, ao pressionar Ctrl+Z esperando o desfazer nativo da palavra, o aplicativo chama faciuUndo(), revertendo o estado do estudo inteiro.

// Linha 9934: if ((e.ctrlKey || e.metaKey) && e.key.toLowerCase() === 'z' && !e.shiftKey) { // Falta verificar: if (['INPUT','TEXTAREA'].includes(document.activeElement?.tagName)) return; e.preventDefault(); faciuUndo(); return; }
Ação Recomendada: Ignorar os atalhos de Undo/Redo globais quando document.activeElement for um elemento de digitação de texto.
